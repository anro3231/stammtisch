FantastiX 3.6.0
===============

serverseitig begrenzter Teilnahme-Abstimmung und lesbarer Abstimmungsübersicht
aller Mitglieder. Vier Dashboard-Kacheln, die letzten zwei Stammtische,
verbindliche Anwesenheit und Gründe getrennt von vorläufigen Zusagen.

Nur GitHub-Pages-Dateien in dein öffentliches Repository laden.
